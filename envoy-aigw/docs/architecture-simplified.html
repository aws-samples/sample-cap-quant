envoy-aigw · Envoy AI Gateway on EKS

One OpenAI / Anthropic-compatible endpoint in front of five Bedrock model families, with two Region channels per model

Request path

  • • Client → AWS WAF → ALB (TLS, 600 s idle) → Envoy AI Gateway
  • • API key checked, then per-client token / request limits (Redis)
  • • Request translated to Bedrock Converse / Anthropic / Mantle
  • • Streams back to the client in the format it sent

Routing & resilience

  • • Two channels per model: us-east-2 (90) and us-east-1 (10)
  • • Passive health check ejects a channel after 3 × 5xx
  • • Retries on 5xx / 429 / connect failure land on the other channel
  • • Scorer re-weights channels every 60 s from Prometheus

Provisioning (repo layout)

  • • infra/ — Terraform: VPC, VPC endpoints, EKS, IAM
  • • apps/ — Terraform: Pod Identity, ACM, Route 53, Cognito, ECR
  • • k8s/ — Helm values + gateway, monitoring, ingress manifests
  • • scripts/deploy.sh (ordered stages) · scripts/smoke.sh
